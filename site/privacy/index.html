TypeRight 개인정보처리방침

최종 수정일: 2026년 9월 21일

TypeRight는 사용자가 입력한 문장을 수집하지도, 저장하지도, 외부로 전송하지도 않습니다. 맞춤법 검사는 전부 사용자의 기기 안에서 이루어집니다.

1. 입력한 내용

  • 맞춤법 검사는 앱에 포함된 규칙 사전을 이용해 기기 안에서만 이루어집니다. 입력한 문장이 서버로 전송되지 않으며, 저장되지도 않습니다.
  • 비밀번호 입력란(일반·웹·숫자 비밀번호)과, 앱이 개인화 학습을 하지 말라고 요청한 입력란(예: 브라우저 시크릿 모드)에서는 맞춤법 검사 자체를 하지 않습니다. 이때 키보드는 '보안 키패드'로 동작합니다.
  • TypeRight는 클립보드를 읽지 않습니다. 사용자가 '복사' 버튼을 눌렀을 때 교정된 문장을 클립보드에 넣기만 합니다.

2. 계정

  • TypeRight는 계정이나 로그인이 없습니다. 이름, 이메일 주소, 전화번호를 받지 않습니다.

3. 기기에 저장되는 것

  • 키보드 설정(자판 종류, 피드백 모드, 진동·소리), 사용자가 직접 만든 단축어, 최근 사용한 이모지는 기기 안에만 저장됩니다.
  • 다른 기기와 동기화되지 않으며, 앱을 삭제하면 함께 지워집니다.

4. 사용 통계 (Google Firebase Analytics)

앱을 개선하기 위해 익명 사용 통계를 수집합니다. 수집되는 항목은 다음과 같습니다.

  • 기능이 사용된 횟수와 종류(예: 키보드가 표시된 횟수, 교정을 적용한 횟수, 선택한 피드백 모드). 값은 숫자이거나 미리 정해진 항목 이름입니다.
  • Google Firebase가 자동으로 수집하는 앱·기기 기본 정보: 앱 버전, 기기 모델, 운영체제 버전, IP 주소로 추정한 대략적인 국가·지역, 그리고 앱 설치마다 무작위로 만들어지는 식별자.

다음 항목은 수집하지 않습니다.

  • 입력한 글자, 교정된 단어 — 어떤 형태로도 전송되지 않습니다.
  • 사용자가 타이핑하고 있는 앱의 이름 — 메신저 / SNS / 업무 / 브라우저 / 기타 다섯 가지 분류로만 기록합니다.
  • 광고 ID(Advertising ID) — 앱에서 수집을 껐습니다. TypeRight는 광고를 표시하지 않습니다.
  • 이름·이메일·전화번호 등 사용자를 직접 식별하는 정보.

5. 제3자 제공

위 4항의 사용 통계가 Google에 전달되는 것 외에, 어떤 정보도 제3자에게 제공하거나 판매하지 않습니다. Google의 데이터 처리에 대해서는 Firebase 개인정보 보호 및 보안을 참고해 주세요.

6. 권한

  • 저장공간 쓰기 (Android 9 이하에서만): 만든 짤 카드 이미지를 갤러리에 저장할 때만 사용합니다. Android 10 이상에서는 이 권한 없이 저장합니다.
  • TypeRight는 연락처, 위치, 카메라, 마이크에 접근하지 않습니다.

7. 아동

TypeRight는 아동을 대상으로 하지 않으며, 아동에게서 의도적으로 개인정보를 수집하지 않습니다.

8. 방침 변경

이 방침이 바뀌면 이 페이지의 최종 수정일을 갱신하고, 중요한 변경은 앱 업데이트 설명에 함께 알립니다.
