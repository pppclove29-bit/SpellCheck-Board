# 사람이 직접 해야 하는 일 (코드로 대체 불가)

> 코드로 가능한 작업은 전부 에이전트가 진행한다. 이 문서는 **계정·결제·심사·실기기·사람 판단**이 필요해서
> 코드로는 끝낼 수 없는 항목만 모은 것이다. 각 항목은 "없으면 무엇이 막히는지"를 함께 적었다.

## E. 순서 권장

1. **A1 (Play 계정)** — 승인에 시간 걸림, 먼저 찔러두기
2. **A3 (OAuth) + A7 (OpenAI) + A8 (Vercel)** — 이 셋이 끝나면 앱이 "실제로" 동작하기 시작. D5·D7 검증 가능
2-1. **A9 (Firebase)** — 계측은 출시 **전에** 켜 놓아야 첫 주 데이터가 남는다. 나중에 켜면 초기 리텐션을 영영 못 봄
3. **B1·B2 (방침·데이터보안)** — 내부 테스트 업로드 전에 필요
4. **A2·A4 (구독+영수증 검증) / A5·A6 (AdMob)** — 수익 경로. 코드는 미리 붙여둠
5. **C1 (멘트 검수)** — 출시 전 아무 때나, 단 출시 전에는 반드시
6. **D1~D8** — 위 항목들이 갖춰지는 대로 순차 확인
