# Play 스토어 등록 정보 초안 (2026-09-21)

온디바이스 전용 출시 기준이다. **이번 빌드에 없는 기능은 한 줄도 쓰지 않았다** —
AI 교정, 로그인, 구독, 광고, 경찰 모드의 입력 차단, 기기 간 동기화는 전부 빠져 있다.
근거는 [planning-and-dev-log.md](planning-and-dev-log.md) 14절, 사실 확인은 [privacy-claims.md](privacy-claims.md).

수치는 `shared/korean-rules.json` 실측값이다(사전 193 · 패턴 11 · 매운맛 멘트 55 = 사전 48 + 패턴 7).
**규칙을 늘리면 이 문서도 같이 고친다.**

---

## 앱 이름

```
TypeRight - 맞춤법 키보드
```

## 짧은 설명 (80자 제한)

```
맞춤법을 고쳐 주는 한국어 키보드. 검사는 전부 기기 안에서 하고 서버로 보내지 않아요.
```

대안 (고를 것):

```
틀린 맞춤법을 바로 잡아 주는 키보드. 로그인도, 광고도, 서버 전송도 없어요.
```

```
오타를 치는 순간 잡아 주는 한국어 키보드. 전부 기기 안에서 동작해요.
```

## 자세한 설명 (4000자 제한)

```
맞춤법을 고쳐 주는 한국어 키보드입니다.
치는 동안 틀린 표기를 찾아 제안하고, 왜 틀렸는지 한 줄로 알려줍니다.

■ 전부 기기 안에서 동작합니다

맞춤법 검사는 앱에 들어 있는 규칙 사전으로 이루어집니다.
입력한 문장이 서버로 전송되지 않고, 저장되지도 않습니다.
로그인도 필요 없습니다. 설치하고 키보드를 켜면 바로 쓸 수 있습니다.

비행기 모드에서도 똑같이 동작합니다.

■ 무엇을 잡아 주나요

자주 틀리는 표기 193개와 패턴 규칙 11개를 담았습니다.

· 몇일 → 며칠
· 갈께 → 갈게
· 어의 → 어이
· 할수있 → 할 수 있
· 않되요 → 안 돼요
· 내꺼 → 내 거

제안 칩을 누르면 바로 고쳐지고, 그냥 두면 아무 일도 일어나지 않습니다.
맞는 문장을 틀렸다고 우기지 않도록, 문맥에 따라 갈리는 표현은 확실한 경우만 규칙에 넣었습니다.

■ 잔소리 강도를 고를 수 있습니다

같은 오타라도 어떻게 말해 줄지 세 가지 중에 고르세요.

· 🌶️ 매운맛 훈수 — 유쾌한 한 마디로 콕 집어 줍니다 (전용 멘트 55개)
· 🍎 상냥한 선생님 — 왜 그렇게 쓰는지 정중하게 설명해 줍니다
· 🚨 맞춤법 경찰 — 오타를 찾으면 진동으로 알려 줍니다

앱별 자동 모드를 켜면 메신저·SNS에서는 매운맛으로, 업무용 앱과 메일에서는 선생님으로
알아서 바뀝니다. 앱마다 직접 정할 수도 있습니다.

■ 📸 짤로 만들어 공유하기

받은 훈수를 말풍선 카드 이미지로 만들어 갤러리에 저장하거나 친구에게 보낼 수 있습니다.
검사한 문장만 들어가고, 전화번호나 이메일 같은 개인정보는 가려집니다.

■ 키보드를 바꾸지 않아도 검사할 수 있습니다

다른 키보드를 쓰고 있어도 됩니다.
어느 앱에서든 글자를 드래그해 선택하고 메뉴에서 [맛춤뻡 검사]를 누르면
바로 검사 결과가 뜹니다. 수정할 수 있는 입력란이면 그 자리에서 고쳐 넣습니다.

■ 키보드 기본기

· 두벌식과 천지인 자판
· 이모지 패널 (8개 분류 + 최근 쓴 이모지)
· 상단 행을 길게 누르면 숫자 입력
· 자주 쓰는 문구를 단축어로 등록 (ㅈㅅ → 죄송합니다)
· 키 진동·소리 켜고 끄기

■ 비밀번호는 건드리지 않습니다

비밀번호 입력란과 브라우저 시크릿 모드에서는 맞춤법 검사 자체를 하지 않고
'보안 키패드'로 바뀝니다. 글자를 읽지도, 검사하지도 않습니다.

TypeRight는 클립보드를 읽지 않습니다.
연락처·위치·카메라·마이크에도 접근하지 않습니다.

■ 광고도, 구독도 없습니다

지금 버전에는 광고가 없고 결제도 없습니다. 모든 기능을 무료로 쓸 수 있습니다.
앱을 개선하기 위한 익명 사용 통계는 수집하지만, 입력한 글자는 어떤 형태로도 전송되지 않습니다.
자세한 내용은 개인정보처리방침을 확인해 주세요.
https://pppclove29-bit.github.io/SpellCheck-Board/privacy/

■ 시작하기

1. 앱을 열고 'TypeRight 키보드 켜기'를 누릅니다
2. 시스템 설정에서 TypeRight를 켭니다
3. '키보드 선택하기'로 TypeRight를 고릅니다

의견이나 오탐 신고는 언제든 메일로 보내 주세요.
```

## 쓰지 않은 것 (의도적)

| 쓰지 않은 표현 | 이유 |
|---|---|
| AI, 인공지능, GPT | 이번 빌드에 AI 교정이 없다. 코드는 `cloud` 플레이버에 있지만 출시 빌드에는 안 들어간다 |
| 로그인, 계정, 동기화 | 전부 꺼져 있다 |
| PRO, 구독, 프리미엄 | 결제 SDK 자체가 APK에 없다 |
| 경찰 모드의 "입력 차단" | 이번 빌드는 **진동 경고까지**다. 차단은 PRO 기능이라 빠졌다 |
| "완벽한 맞춤법 검사" 류 | 규칙 기반이라 잡지 못하는 오류가 있다. 과장하면 리뷰로 돌아온다 |
| 경쟁 앱·타사 앱 이름 | 불필요한 분쟁 소지 |
